### Selected work

- [TrackMania Mac](https://github.com/vakesz/TrackMania-MacOS) — one app
  that installs and runs TrackMania Nations Forever on Apple Silicon
  Macs, with a patched Wine runtime.
- [Glasstual](https://github.com/vakesz/Glasstual) — native IRC client
  for macOS 26 and later on Apple silicon, an independent fork and
  continuation of Textual. Swift, SwiftUI, AppKit.
- [Docket](https://github.com/vakesz/docket) — self-hostable triage for
  GitHub Issues and Azure DevOps work items, with an AI assistant whose
  writes go through a proposal, diff and confirm step. Next.js, Postgres.
- [Drifting Thoughts](https://github.com/vakesz/Drifting-Thoughts) — small
  iOS journal that turns a thought into a shareable card and keeps
  everything on the device. SwiftUI, SwiftData.
- [Dotfiles](https://github.com/vakesz/dotfiles) — repeatable setup for
  macOS, Linux and WSL, built on GNU Stow and the XDG layout.
